# Password Hash Tool

A privacy-first, browser-only utility for hashing and verifying passwords, encrypting text, and computing HMACs. Passwords and secrets never leave your device.

## Privacy

- All cryptography is performed locally in the browser.
- The page has no form submission, analytics, database, password storage, or application backend.
- The Argon2, bcrypt, and scrypt implementations are loaded from pinned CDN packages; Blake2b is lazy-loaded from a pinned ESM bundle. Review or self-host these assets if you need an offline or higher-assurance setup.

## Features

Everything lives in a single card: pick an operation from the combobox — a hash algorithm, AES-256-GCM encryption/decryption, or HMAC — and the form adapts to it. Below the form, a dedicated password-verification section is always available.

### Hash a password

| Algorithm | Status | Encoded format |
|---|---|---|
| Argon2id | Recommended default | `$argon2id$v=19$m=…,t=…,p=…$…$…` (standard PHC) |
| scrypt | Recommended | `$scrypt$ln=…,r=…,p=…$…$…` |
| bcrypt | Recommended | `$2a$…` (standard bcrypt) |
| PBKDF2-HMAC-SHA256/384/512 | Recommended / policy-driven | `$pbkdf2-sha256$iterations$…$…` (passlib-compatible) |
| Argon2d, Argon2i | Variants for specific threat models | `$argon2d$…` / `$argon2i$…` (standard PHC) |
| Balloon-style | Educational only | `$balloon$s=…,t=…$…$…` |
| aehash | Experimental only | `$aehash$o=…$…$…` |
| Blake2b-KDF | Educational only | `$blake2b-kdf$i=…$…$…` |

Recommended defaults: Argon2id with m=65536 KiB, t=3, p=1; scrypt with N=2^15, r=8, p=1; bcrypt cost 12; PBKDF2 with 600,000 iterations.

The Balloon-style, aehash, and Blake2b-KDF entries are simplified teaching constructions, **not** the standardized Balloon hash or any reviewed password-hashing scheme. Do not use them to store real passwords.

### Verify a password

Paste any hash generated by this tool — the algorithm and parameters are detected automatically from the encoded string, and verification reuses the salt and parameters embedded in the hash. Argon2, bcrypt, scrypt, and PBKDF2 hashes produced by other tools in the same standard formats are also accepted.

### Encrypt / decrypt text

AES-256-GCM with a PBKDF2-SHA256-derived key (default 600,000 iterations). Hashes are one-way, but this section produces reversible ciphertext for storing notes or sharing secrets. The output is a self-describing string:

```text
enc-v1$pbkdf2-sha256$i=600000$<salt>$<iv>$<ciphertext>
```

Decryption requires the same password; a wrong password simply fails authentication (GCM tag mismatch) without leaking information.

### HMAC (message authentication)

Computes a keyed HMAC-SHA256/384/512 tag over a message using Web Crypto. HMAC authenticates data integrity and origin — it is **not** suitable for password storage because it is fast to compute.

## Theme

The interface follows the operating-system theme by default. A single sun/moon control lets visitors switch between light and dark mode. The selected mode is saved only in the browser's `localStorage` under `theme-preference`.

## Output compatibility

- Argon2 outputs are standard PHC strings, compatible with Rust's `argon2` crate (`Argon2::default()` for Argon2id).
- PBKDF2 outputs follow the passlib `$pbkdf2-sha256$iterations$salt$hash` encoding.
- bcrypt outputs are standard `$2a$` Modular Crypt Format strings.
- scrypt outputs use a self-describing PHC-style `$scrypt$ln=…,r=…,p=…$salt$hash` encoding.

## Security notes

- Always use the recommended algorithms (Argon2id, scrypt, bcrypt, PBKDF2) for real password storage; prefer Argon2id for new systems.
- Never use raw hashes (MD5, SHA-1, plain SHA-2) or fast HMACs to store passwords.
- Educational/experimental algorithms in this tool are clearly labeled and should stay that way.
- In production, verify passwords server-side; this tool is for generating and inspecting hashes locally.
