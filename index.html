Argon2id Password Hash Tool

Generate a password hash for applications using Argon2id. Your password is processed in this browser and is never sent to a server or saved by this page.

Argon2id parameters

Password hash

Store this complete value in your database's password_hash field. Keep the original password private.

Compatibility and privacy

The output uses the standard PHC string format beginning with $argon2id$, compatible with Rust's argon2 crate when using its default Argon2id verifier. This page makes no API requests; the Argon2 WebAssembly library runs entirely in your browser.
