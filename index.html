Password Hash Tool

Hash and verify passwords, encrypt text, and compute HMACs — all in this browser. Nothing is sent to a server or saved by this page.

Verify a password

Paste a hash and enter the password to check. The algorithm is detected automatically from the hash string.

Compatibility and privacy

Argon2 outputs are standard PHC strings, compatible with Rust's argon2 crate. bcrypt ($2a$…) and PBKDF2 (passlib-style $pbkdf2-sha256$…) use common encoded formats, while scrypt uses this tool's self-describing $scrypt$ln=…,r=…,p=…$salt$hash format. Educational algorithms (Balloon-style, aehash, Blake2b-KDF) use this tool's own formats and are for learning only. This page makes no API requests; all cryptography runs locally, and the pinned CDN libraries contain the hashing implementations.
